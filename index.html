▶ How to read the cipher

Each word becomes an independent token joined by ~~ and wrapped in << >>. The token index (1-based) drives the Caesar shift — word 1 shifts by 1, word 2 by 2, and so on.

▶ Layer order matters

Encode: L1 → L2 → L3  |  Decode: L3 → L2 → L1
L3 is self-inverse (applying it twice restores the original), so the decode step for L3 is identical to encode.

▶ Caesar wrap-around

Shifts wrap the alphabet: z shifted +1 becomes a. Case is preserved. Non-letter characters (@, digits, symbols) are never shifted.

▶ Pair-swap edge case

If the token body has an odd number of letters, the last letter is left in place — only complete pairs are swapped.
