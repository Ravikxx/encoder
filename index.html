▶ Why this is hard to crack

Without the passphrase, all 5 layers are unknown: the substitution alphabet (26! ≈ 4×10²⁶ possibilities), the 64-entry shift table (25⁶⁴ ≈ 10⁸⁹ possibilities), and the 64-entry Vigenere key. The length tag is obfuscated using a key-derived base-26 alphabet, so word lengths are hidden. The token separator is also key-derived, so even splitting tokens requires the key.

▶ Layer stack (encode order)

L0 Key-seeded Fisher-Yates monoalphabetic substitution → L1 Reverse body + blind 2-letter tag → L2 Key-seeded non-linear Caesar per token → L3 Adjacent letter-pair swap (self-inverse) → L4 Per-token Vigenere using key-derived stream

▶ Wrong key behaviour

Using the wrong passphrase during decode silently produces garbage — no error is thrown. The only way to verify correctness is recognising the output as valid plaintext.
